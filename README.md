# LookCraft

LookCraft is a wardrobe app. It keeps an inventory of the pieces in your closet and helps you style any piece you pick, with outfit suggestions built from what you already own.

Features:
- Closet inventory with photos and details for each piece
- Outfit suggestions for a chosen piece
- Optional, read-only Pinterest connection: pins you pick from your own boards guide the suggestion and are shown with a link back to Pinterest

Currently in development.
